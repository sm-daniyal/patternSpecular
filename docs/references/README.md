# Statutory & Academic References

This directory contains statutory, regulatory, and peer-reviewed reference materials grounding Pattern Specular's multi-jurisdictional compliance engine and multi-agent adjudication models.

---

## 1. Compliance Frameworks & Jurisdictions

* **[`compliance_frameworks.md`](compliance_frameworks.md)**: Comprehensive legal grounding across all supported jurisdictions:
  * **India (`IN`)**: Code on Wages 2019, RPwD Act 2016, Transgender Persons Act 2019.
  * **Singapore (`SG`)**: Tripartite Guidelines on Fair Employment Practices (TAFEP), Workplace Fairness Legislation (WFL).
  * **United States (`US`)**: Title VII Civil Rights Act 1964, ADEA, ADA, EEOC Guidelines.
  * **United Kingdom (`UK`)**: Equality Act 2010 (Schedule 9 Occupational Requirements).
